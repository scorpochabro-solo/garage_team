# ГАРАЖ · garage.team — полная пересборка сайта (2027)

Статический сайт автотехцентра «Гараж» (Нижний Новгород), собранный заново на основе
**всего контента текущего garage.team**: 28 направлений услуг, 99 страниц услуг с ценами,
команда, отзывы, галерея, автозапчасти, каталоги, оплата, доставка, регистрация, соглашение.
Палитра бренда сохранена: белый · чёрный · зелёный `#00963D`. Логотип — оригинальный.

## Запуск

```bash
python3 build.py          # собирает ./dist (нужен только Pillow для картинок)
python3 -m http.server 5181 --directory dist
```

Открыть <http://localhost:5181/>. В `.claude/launch.json` рабочего каталога есть конфиг `garage-2027`.

## Фото услуг (kie.ai, GPT Image 2.5)

Фото сгенерированы, это не снимки сервиса «Гараж». Поэтому на странице у фото стоит подпись «иллюстрация»
(`PHOTO_LABEL` в `build/services.py`), и подписывать их как «фото наших работ» нельзя. Реальные фото из боксов
кладутся в тот же `src/assets/img/photo/<slug>.jpg`, тогда подпись стоит убрать.

```bash
python3 tools/kie_images.py --balance          # остаток кредитов
python3 tools/kie_images.py --dry-run          # показать итоговые промты, ничего не вызывать
python3 tools/kie_images.py                    # сгенерировать всё из data/service_photos.json, чего ещё нет
python3 tools/kie_images.py --only pokraska --force   # перегенерировать одно фото
python3 build.py                               # страница подхватит фото, если файл существует
```

- Новая страница: добавить элемент в `data/service_photos.json` (`page`, `slug`, `alt`, `scene`). Общий фотостиль
  (объектив, свет, запрет надписей и логотипов) дописывает скрипт из константы `STYLE`.
- Модель по умолчанию `gpt-image-2-5-sunburst-text-to-image`, 3:2, 2K. Фактическая цена на 2026-09-21:
  10 кредитов за фото (1 USD = 200 кредитов, то есть около 0,05 USD). `--model flare` быстрее.
- Номера задач хранятся в `tools/.kie_tasks.json`: прерванный запуск продолжает ждать и докачивать результат,
  а не платит второй раз. Файлы результата лежат на медленном хосте, поэтому скачивание идёт с докачкой.

## Схема услуг: как устроена и почему не тормозит

Прежняя «лупа» с увеличением заставляла браузер перерисовывать стекло на каждом кадре (`left/top`, `background-position`,
`mix-blend-mode`, анимируемый `filter` на всей машине) и пересчитывать стили 22 пульсирующих точек. 21.09.2026 в отдельной
лаборатории сравнили три замены и взяли вариант «прицел и прожектор» (архив лаборатории с вариантами A и B:
`_plans/lens-lab-2026-09-21.tar.gz`, папка не в репозитории). Что теперь в `src/assets/js/car.js` и `car.css`:

- Прицел (`.reticle`) и тёмная вуаль с мягким отверстием (`.spot` + `<canvas>` 512 px, растянутый CSS) создаются скриптом,
  двигаются только через `transform`, каждый на своём слое. Никаких копий картинки машины.
- Положение сглаживает один цикл `requestAnimationFrame`, который останавливается, когда всё замерло. Обработчики указателя
  только запоминают координаты. Геометрия (размеры сцены, положение пунктов списка) читается одним пакетом при появлении
  секции и при ресайзе, а не в каждом кадре.
- Во время сканирования не пульсируют неактивные точки (`.is-roaming`) и не приглушается список; бесконечные анимации
  секции ставятся на паузу вне экрана (`.is-paused`), бегущая строка и подсказка прокрутки тоже (`.is-offscreen`, `core.js`).
- Убраны `backdrop-filter` у ридаута и `drop-shadow` у HUD-линии.

Настройки в начале `car.js`: `SNAP` (радиус прилипания), `TAU_ROAM` / `TAU_JUMP` (плавность), `VEIL` (плотность тени),
`TOUR_MS` (шаг авто-тура). Размер прицела — `.reticle { width }` в `car.css`.

Замер 2026-09-22 (Chromium на видеокарте Apple M2, процессор замедлен в 4 раза, медиана трёх прогонов, 4 с ведения по машине):
процессор 2 800 мс → 1 536 мс, видеокарта 326 мс → 196 мс; при переходах между услугами видеокарта 346 мс → 126 мс.

## Чего компания не делает

Тонировка и установка сигнализаций: услуги не оказываются (уточнено у владельца 2026-09-21). Страниц, пунктов схемы
и упоминаний в текстах быть не должно. Из должностей двух сотрудников в `data/site.json` слово «тонировка» убрано.

## Бэкенд: что подключить после выкладки

Фронтенд отправляет формы на те же адреса, что и текущий сайт:

| Действие | Запрос |
|----------|--------|
| Заявка (3 шага) | `POST /call/request` (поля `request_part[...]`) |
| Заказать звонок | `POST /call` (`contact_name`, `contact_phone`, `car`, `vin_code`, `message`) |
| Модели по марке | `POST /findcar/requestmodels/id/<brand_id>` → `{data:[{id,name,year_start,year_end}]}` |
| Модификации | `POST /findcar/requestsizes/` (`id`, `year`) → `{data:[{id,name}]}` |
| Вход | `POST /login/popup`; восстановление: `/email/lostpass`, `/sms/lostpass` |
| Регистрация | `POST /registration` (`RegistrationForm[...]`) |

Если бэкенд недоступен (например, на статическом хостинге), формы показывают понятную ошибку
с телефоном, а выбор автомобиля автоматически переключается на ручной ввод.
Корзина (`#cart-link`) ведёт на раздел автозапчастей — подключите к реальной корзине магазина.
Ссылки каталогов `/cats/zapchasti_na_*.html` и поиск `/search/` обслуживаются существующим бэкендом.
Страницу `404.html` нужно назначить в настройках хостинга/nginx (`error_page 404 /404.html`).

## Деплой

- **GitHub Pages (превью для заказчика):** <https://scorpochabro-solo.github.io/garage_team/>.
  Репозиторий `scorpochabro-solo/garage_team`, Pages читает папку `docs/` ветки `main`.
  Пересобрать и выложить:

  ```bash
  python3 build.py --base /garage_team --out docs && git add -A && git commit -m "build: pages" && git push
  ```

- **Продакшен на своём домене (garage.team):** `python3 build.py` без флагов → `dist/`, залить содержимое в корень хостинга.
  `--base` нужен только когда сайт живёт в подпапке.

## Технологии

Семантический HTML5, современный CSS (custom properties, grid, clamp, `dialog`, scroll-snap),
ванильный JS без зависимостей, self-hosted шрифты (Unbounded, Manrope, JetBrains Mono), WebP.
Учитываются `prefers-reduced-motion`, клавиатурная навигация, ARIA-атрибуты, контраст AA.
