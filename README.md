# ГАРАЖ · garage.team — полная пересборка сайта (2027)

Статический сайт автотехцентра «Гараж» (Нижний Новгород), собранный заново на основе
**всего контента текущего garage.team**: 28 направлений услуг, 99 страниц услуг с ценами,
команда, отзывы, галерея, автозапчасти, каталоги, оплата, доставка, регистрация, соглашение.
Палитра бренда сохранена: белый · чёрный · зелёный `#00963D`. Логотип — оригинальный.

## Запуск

```bash
python3 build.py          # собирает ./dist (нужен только Pillow для картинок)
python3 -m http.server 5181 --directory dist
```

Открыть <http://localhost:5181/>. В `.claude/launch.json` рабочего каталога есть конфиг `garage-2027`.

## Что добавлено

- Интерактивная схема услуг с «диагностической лупой»: при наведении на услугу круглая линза скользит по
  автомобилю к нужному узлу и показывает его с увеличением 2,1× и зелёными контурами «рентгена», остальная машина
  приглушается, рисуется HUD-линия от подписи, в ридауте — описание, стартовая цена и номер зоны. На десктопе лупой
  можно водить по машине мышью: рядом с точкой она «прилипает» к узлу. Есть авто-тур, тач и клавиатура.
  Фото — BMW Alpina B3 Touring клиента (`src/assets/img/car.png`), координаты точек — `data/hotspots.json`.
- Короткие вводные тексты на страницах услуг (`data/descriptions.json`) — на старом сайте их не было,
  написаны нейтрально, без обещаний; при желании замените своими.
- Поиск по услугам, фильтр каталогов «Легковые / Грузовые», лайтбокс, счётчики, JSON-LD (AutoRepair),
  sitemap.xml, robots.txt, Open Graph, favicon/apple-touch-icon.
- Согласие на обработку персональных данных в формах (чекбокс) — обязательное по 152-ФЗ.

## Бэкенд: что подключить после выкладки

Фронтенд отправляет формы на те же адреса, что и текущий сайт:

| Действие | Запрос |
|----------|--------|
| Заявка (3 шага) | `POST /call/request` (поля `request_part[...]`) |
| Заказать звонок | `POST /call` (`contact_name`, `contact_phone`, `car`, `vin_code`, `message`) |
| Модели по марке | `POST /findcar/requestmodels/id/<brand_id>` → `{data:[{id,name,year_start,year_end}]}` |
| Модификации | `POST /findcar/requestsizes/` (`id`, `year`) → `{data:[{id,name}]}` |
| Вход | `POST /login/popup`; восстановление: `/email/lostpass`, `/sms/lostpass` |
| Регистрация | `POST /registration` (`RegistrationForm[...]`) |

Если бэкенд недоступен (например, на статическом хостинге), формы показывают понятную ошибку
с телефоном, а выбор автомобиля автоматически переключается на ручной ввод.
Корзина (`#cart-link`) ведёт на раздел автозапчастей — подключите к реальной корзине магазина.
Ссылки каталогов `/cats/zapchasti_na_*.html` и поиск `/search/` обслуживаются существующим бэкендом.
Страницу `404.html` нужно назначить в настройках хостинга/nginx (`error_page 404 /404.html`).

## Деплой

- **GitHub Pages (превью для заказчика):** <https://scorpochabro-solo.github.io/garage_team/>.
  Репозиторий `scorpochabro-solo/garage_team`, Pages читает папку `docs/` ветки `main`.
  Пересобрать и выложить:

  ```bash
  python3 build.py --base /garage_team --out docs && git add -A && git commit -m "build: pages" && git push
  ```

- **Продакшен на своём домене (garage.team):** `python3 build.py` без флагов → `dist/`, залить содержимое в корень хостинга.
  `--base` нужен только когда сайт живёт в подпапке.

## Технологии

Семантический HTML5, современный CSS (custom properties, grid, clamp, `dialog`, scroll-snap),
ванильный JS без зависимостей, self-hosted шрифты (Unbounded, Manrope, JetBrains Mono), WebP.
Учитываются `prefers-reduced-motion`, клавиатурная навигация, ARIA-атрибуты, контраст AA.
