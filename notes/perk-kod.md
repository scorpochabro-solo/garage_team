# Плюшка «Расшифровка кода ошибки» (`kod`)

**Где смотреть:** `/services/diagnostika/komputernaa-diagnostika.html#kod` — страница «Компьютерная диагностика», блок сразу
после вводного текста (перед ценами). Локально: `python3 build.py && python3 -m http.server 5193 --directory dist`, затем
<http://localhost:5193/services/diagnostika/komputernaa-diagnostika.html#kod>. Второй вход — с главной: «Что горит на панели?» →
значок Check Engine → строка «Есть код ошибки? Расшифруйте» ведёт прямо на блок. Ссылка на конкретный код:
`…/komputernaa-diagnostika.html#kod-p0420` — откроет P0420 на экране расшифровки.

Ветка `perk/kod` (от `photos`, `794723f`).

## Что сделано

Блок в виде экрана диагностического сканера (надпись в строке состояния «OBD-II · SAE J2012»):

- **Ввод.** Поле «Код ошибки» и кнопка «Расшифровать». Код понимается в любом привычном написании: `P0301`, `p0301`,
  `P0 301`, `P0-301`, `P 0 3 0 1`, кириллическая `Р0301`, буква O вместо нуля (`PO301`), русская раскладка (`З0301` = P0301,
  `Г0100` = U0100), широкие символы с телефона. Можно несколько кодов сразу — через запятую, пробел, точку с запятой,
  с новой строки или даже слитно (`P0301P0171`); повторы убираются, показываются первые 10 («Показаны первые 10 кодов.»).
  Слова вокруг («код ошибки P0420», «у меня P0301 и P0171») не мешают; одинокие «и», «в», «с», «у» — слова, а не буквы кода.
  Рядом с настоящими кодами посторонние числа (год, пробег, «B1S1» из описания сканера) молча пропускаются.
- **Пока человек печатает**, законченный код расшифровывается сразу; недопечатанный — ещё не ошибка. Если уже расшифрованный
  код начали исправлять, старый ответ приглушается, пока новый не будет набран. **Ошибки ввода — дружелюбные**, с тем, что
  было введено: нет буквы (««0301»: в начале кода нужна буква — P, B, C или U, например P0301.»), не та буква, второй знак не
  0–3, не те символы, не та длина, «не похоже на код», пустое поле, текст без кода (все тексты — ниже).
- **Ответ** для каждого кода:
  1. код на «экране» — пять ячеек, под ними скобки «система · тип · группа · номер»; ячейки «выпадают» по очереди, по стеклу
     один раз проходит световая полоса (только transform/opacity, один раз на новый код, в покое ничего не крутится);
  2. разбор по знакам: **система** (P — двигатель и коробка, B — кузов, C — шасси, U — связь блоков), **тип** (общий код SAE
     или код производителя, с правильными диапазонами P0/P2 общие, P1 производителя, P3000–P33FF производителя,
     P3400–P3FFF общие; у B/C/U: 0 общий, 1–2 производителя, 3 — запасной диапазон стандарта), **группа** по третьему знаку
     (у P0, P2, U0 — как в стандарте; у P1 — «обычно …», потому что стандарт лишь просит производителей держать те же группы),
     **номер** неисправности. Наведение на строку подсвечивает её ячейки;
  3. для 100 частых общих кодов из справочника — «Что означает» (стандартное значение SAE простыми словами), «Что обычно
     проверяют», у 10 кодов строка «Проверку лучше не откладывать.», ссылка на подходящую страницу услуг и оговорка «Это общее
     значение кода по стандарту SAE. Одну и ту же ошибку дают разные причины — какая из них у вашей машины, покажет диагностика.»;
  4. код производителя (янтарная подсветка второго знака): «Это код производителя: его значение зависит от марки и модели.
     Точную расшифровку для вашей машины даст компьютерная диагностика.»; общий код не из справочника — «Этого кода нет
     в нашем справочнике. Точную расшифровку…»; запасной диапазон (B3/C3/U3) — «Такие коды встречаются редко. Точную…».
- **Несколько кодов** — список как в настоящем сканере («Коды · 3»: код и суть в одну строку), выбранный открыт ниже.
- **Заявка:** кнопка «Записаться на компьютерную диагностику» открывает существующее окно «Заказать звонок» с комментарием
  «Хочу записаться на компьютерную диагностику. Коды ошибок: P0301, P0171.» (без кодов — первая фраза); под кнопкой
  «Коды P0301, P0171 попадут в комментарий к заявке.» Механизм тот же, что у остальных кнопок (`data-modal`/`data-preset`).
- **«Например»:** P0300, P0171, P0420, P0700 — одно нажатие расшифровывает.
- **Справочник частых кодов** под экраном: 100 кодов в 8 раскрывающихся группах (`<details>`), у каждого — значение,
  «Обычно проверяют: …», ссылка на страницу услуги; пояснения «банк», «датчик 1 и 2», «A и B». Со скриптом код в справочнике —
  кнопка: расшифровывает его на экране выше и прокручивает к нему.
- **Без JavaScript и для поисковиков** весь справочник (все 100 кодов с текстами) и разобранный пример P0301 («Пример»)
  есть в HTML; поле ввода в этом случае скрыто (`@media (scripting: none)`), JS только улучшает.

## Что сказано о структуре кода (SAE J2012) и чего нарочно нет

- Буква: P — Powertrain, B — Body, C — Chassis, U — Network (описания — ниже, в текстах).
- Второй знак: 0 общий; 1 производителя; 2 у P — общий, у B/C/U — производителя; 3 у P — P3000–P33FF производителя,
  P3400–P3FFF общий; у B/C/U — запасной диапазон.
- Третий знак (группа): у P0 — 0 топливо, воздух и контроль выбросов; 1 подача топлива и воздуха; 2 то же, цепи форсунок;
  3 зажигание и пропуски; 4 системы снижения выбросов; 5 скорость, холостой ход, вспомогательные сигналы; 6 блок управления
  и выходные цепи; 7–9 коробка; A–C гибридная силовая установка. У P2 — те же группы (A — подача топлива и воздуха),
  у P1 — те же с «обычно», у U0 — 0 электрика сети, 1–2 связь между блоками, 3 программы блоков, 4 данные.
- **Не расшифровываем** (не уверен в стандарте или его нет): третий знак у B и C, у P0D–P0F, P1A–P1F, P29, P2B–P2F, P3, U1–U3.
  Там показывается «Номер» из трёх знаков и «Точную расшифровку для вашей машины даст компьютерная диагностика».
- Нумерация кодов десятичная (после P0139 идёт P0140, не P013A), хотя в коде бывают буквы A–F; это проверяет тест.
- В значениях «банк 1», «датчик 2», «цилиндре 3», «детонации 1» число привязано неразрывным пробелом — не уходит на новую строку.

## Ограничения и решения

- Значения — общие определения SAE J2012 простыми словами; «Что обычно проверяют» — общая практика, не диагноз (это
  сказано под каждым ответом). Кодов производителей в справочнике нет: их смысл зависит от марки.
- Для 2 кодов подходящей страницы услуг нет — P0455 и P0456 (утечки в системе улавливания паров топлива): ссылки у них нет,
  есть кнопка записи на диагностику.
- Катализатор, лямбда-зонды, EGR ведут только на ремонт («Ремонт выхлопной системы», «Ремонт двигателя»), никогда на удаление
  или чип-тюнинг; слов «удалить», «отключить», «прошить», «заглушка» в текстах нет (проверяет тест).
- Четыре цифры без буквы рядом с настоящими кодами считаются посторонним числом (годом, пробегом) и пропускаются молча;
  если в поле только «0301», будет подсказка про букву.
- Вход только через поле и справочник; истории запросов и localStorage нет.
- Блок стоит сразу после вводного текста, как шинный калькулятор; переставить ниже цен — одна строка в `build/services.py`.

**Замечено вне плюшки, не трогал:**
- белый текст на зелёной кнопке сайта (`.btn--primary`, в том числе «Записаться на компьютерную диагностику») — контраст
  3,9:1, для текста 15 px нужно 4,5:1; это общая кнопка бренда;
- в Chromium на ширине 320 px после закрытия окна «Заказать звонок», открытого из середины страницы, у документа остаётся
  завышенная ширина прокрутки (так же с кнопкой шинного калькулятора); на iPhone (WebKit) этого нет.

### Блок и экран
- Надзаголовок «// расшифровка», заголовок «Расшифровка кода ошибки».
- Вводный текст: «Код ошибки — например, P0301 — читается по знакам: буква называет систему машины, а цифры — тип кода, группу и номер неисправности.» Со скриптом дальше: «Введите свой код: покажем, что он значит и что обычно проверяют при такой ошибке. Можно несколько кодов сразу.»

### Итог под разбором
- Код из справочника: «Это общее значение кода по стандарту SAE. Одну и ту же ошибку дают разные причины — какая из них у вашей машины, покажет диагностика.»
- Код производителя: «Это код производителя: его значение зависит от марки и модели. Точную расшифровку для вашей машины даст компьютерная диагностика.»
- Общий код не из справочника: «Этого кода нет в нашем справочнике. Точную расшифровку для вашей машины даст компьютерная диагностика.»
- Запасной диапазон: «Такие коды встречаются редко. Точную расшифровку для вашей машины даст компьютерная диагностика.»
- У 10 кодов: «Проверку лучше не откладывать.»

### Ошибки ввода
В кавычках — то, что ввёл человек (здесь для примера); «например P0301» в первой строке строится из его цифр.
- «Введите код ошибки — например, P0301.»
- «В тексте нет кода ошибки. Код выглядит так: буква и четыре знака, например P0301.»
- ««0301»: в начале кода нужна буква — P, B, C или U, например P0301.»
- ««A0301»: код начинается с буквы P, B, C или U.»
- ««P4301»: второй знак кода — только 0, 1, 2 или 3.»
- ««P03G1»: после буквы идут цифры, иногда буквы от A до F.»
- ««P030»: в коде пять знаков — буква и четыре цифры, например P0301.»
- ««12345» не похоже на код ошибки.»
