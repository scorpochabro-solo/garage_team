# Плюшка «Шинный калькулятор» (`shiny`)

**Где смотреть:** `/services/sinomontaz.html#shiny` — страница «Шиномонтаж», блок сразу после вводного текста
(перед «От чего зависит стоимость»). Локально: http://localhost:8813/services/sinomontaz.html#shiny (сервер после сдачи остановлен:
`cd wt-p-shiny && python3 build.py && python3 -m http.server 8813 -d dist`).

## Что это

Клиент сравнивает шины, которые стоят сейчас, с теми, что хочет поставить, и сразу видит, что изменится:

- **Ввод:** для каждого размера — три настоящих `<select>` (ширина 135–335 шаг 10, профиль 25–85 шаг 5, диаметр R12–R24)
  и одно текстовое поле, куда можно вписать размер как на шине: «205/55 R16», «205/55R16», «205 55 16», «215-55-р16»,
  «225/45 ZR17 94W» (индексы в конце игнорируются, кириллическая «Р» понимается). Поле и селекты заполняют друг друга.
  Кнопка ⇄ меняет размеры местами. По умолчанию 205/55 R16 → 215/50 R17.
- **Результат** (чистая геометрия маркировки, мгновенно): крупно разница диаметров в процентах и словами
  («Колесо больше на 14,9 мм»), шкала отклонения −6…+6 % с зелёной зоной ±3 %, таблица «Сейчас / Хочу / Разница»:
  наружный диаметр, высота боковины, ширина, клиренс (половина разницы диаметров); спидометр: при 60 / 90 / 110 км/ч
  на спидометре реальная скорость …; вердикт по правилу «до 3 %» с оговоркой про допустимые размеры производителя.
- **Чертёж в масштабе** (SVG): вид сбоку — колесо и диск нового размера, текущий размер пунктиром поверх, оба стоят
  на одной «земле» (видно, как поднимается колесо); вид спереди — ширина и высота шины; проекционные линии по верху,
  масштабная линейка «100 мм». При каждом изменении — один короткий твин трансформаций (0,56 с), без постоянного цикла.
  Масштаб один для обоих колёс; меняется ступенькой, только если колесо выше 700 мм (большие внедорожные размеры).
- **«Как читать маркировку»:** фрагмент боковины «205/55 R16 91V», каждая часть — кнопка; зелёная планка переезжает
  под выбранную часть, ниже объяснение (ширина, профиль, конструкция, посадочный диаметр, индекс нагрузки, индекс скорости).
- **Заявка:** «Записаться на шиномонтаж» открывает существующее окно «Заказать звонок» с комментарием
  «Шиномонтаж: хочу поставить 215/50 R17 вместо 205/55 R16.» (с актуальными размерами; тот же механизм, что
  `G.openModal('call', { message })`, через `data-modal`/`data-preset` из core.js). Рядом ссылка на «Сход-развал»
  (href собирается в Python). Что сервис продаёт шины или диски — нигде не сказано.

## Где в коде

| Файл | Что |
|---|---|
| `build/shiny.py` (новый) | математика, тексты (`TEXTS`, `MARKING`, сноски), разметка блока и SVG, начальное состояние считается на сервере |
| `src/assets/css/shiny.css` (новый) | стили; раскладка через container queries по ширине панели (узкая — одна колонка) |
| `src/assets/js/shiny.js` (новый) | пересчёт, разбор текста, твин чертежа, шкала, маркировка, live-регион, localStorage |
| `tests/test_shiny.py` (новый) | 12 тестов: формулы на ручных примерах, округление, вердикт, разметка |
| `build.py` | `shiny.css` в `CSS_ORDER`, `shiny.js` в `JS_ORDER` (по слову в строке) |
| `build/services.py` | `from . import shiny` и `shiny.block(svc)` после `B.lead(...)` (для остальных 98 страниц возвращает пустую строку) |

Все фразы, которые может показать скрипт, живут в `build/shiny.py` и попадают в JS через `data-*` блока; допустимые размеры
JS берёт из `<option>` селектов, скорости и порог 3 % — тоже из `data-*`. Второй копии констант в JS нет, кроме формул.
Ничего не закоммичено.

## Математика и проверка «руками»

Боковина = ширина × профиль / 100; диск = R × 25,4 мм; наружный диаметр = диск + 2 × боковина.
Считаю в сотых долях миллиметра (там всё целое), показываю десятые с округлением «половина — от нуля»;
разница в таблице = разность показанных чисел, поэтому столбцы всегда сходятся. Реальная скорость = показания × Dновый / Dтекущий.

| Размер | Боковина | Диск | Наружный диаметр |
|---|---|---|---|
| 205/55 R16 | 205 × 0,55 = 112,75 | 16 × 25,4 = 406,4 | 406,4 + 225,5 = **631,9** |
| 215/50 R17 | 107,5 | 431,8 | 431,8 + 215 = **646,8** |
| 235/45 R18 | 105,75 | 457,2 | 457,2 + 211,5 = **668,7** |
| 195/65 R15 | 126,75 | 381,0 | **634,5** |
| 175/65 R14 | 113,75 | 355,6 | **583,1** |
| 225/60 R15 | 135 | 381,0 | **651,0** |

| Сравнение с 205/55 R16 | Разница | % | Клиренс | 60 / 90 / 110 км/ч на спидометре → реально | Вердикт |
|---|---|---|---|---|---|
| 215/50 R17 | +14,9 мм | 14,9 / 631,9 = 2,358 → **+2,4 %** | +7,45 → **+7,5** | 61,41 / 92,12 / 112,59 → **61,4 / 92,1 / 112,6** | в пределах 3 % |
| 235/45 R18 | +36,8 | 5,824 → **+5,8 %** | **+18,4** | **63,5 / 95,2 / 116,4** | больше 3 % |
| 175/65 R14 | −48,8 | −7,723 → **−7,7 %** | **−24,4** | 55,37 / 83,05 / 101,51 → **55,4 / 83,0 / 101,5** | больше 3 % (колесо меньше) |
| 225/60 R15 | +19,1 | 3,023 → показано **+3,0 %** | **+9,6** | **61,8 / 92,7 / 113,3** | в пределах 3 % (вердикт следует показанному числу) |

Совпадение JS и Python проверено в браузере на 47 парах (7 крайних + 40 случайных): все числа, вердикты, текст заявки
и строки трансформаций чертежа одинаковы.

## Тексты на подтверждение владельцу

Заголовок и ввод:
1. Надзаголовок «// калькулятор», заголовок «Шинный калькулятор».
2. «Сравните размер шин, которые стоят сейчас, с теми, что хотите поставить: калькулятор покажет, как изменятся диаметр колеса, клиренс и показания спидометра.»
3. Подписи: «Сейчас стоит», «Хочу поставить», «Ширина», «Профиль», «Диаметр»; кнопка «Поменять размеры местами» (подсказка и для экранного диктора); для диктора у поля: «…: размер шины, например 205/55 R16».
4. Ошибки поля: «Не получилось разобрать размер. Напишите как на шине, например 205/55 R16.» и «Такого размера нет в списке: ширина от 135 до 335 мм, профиль от 25 до 85, диаметр от R12 до R24.»

Чертёж и результат:
5. «вид сбоку», «вид спереди», «100 мм»; легенда «Сейчас 205/55 R16», «Хочу 215/50 R17».

7. «Разница диаметров»; «Колесо больше на … мм» / «Колесо меньше на … мм» / «Диаметр не меняется».
8. Таблица: «Сейчас», «Хочу», «Разница», «Наружный диаметр», «Высота боковины», «Ширина шины», «Клиренс», «половина разницы диаметров».
9. «Спидометр, км/ч», «Показывает», «На самом деле»; сноска «Реальная скорость — если с нынешними шинами спидометр показывал точно.»

Вердикт (жирное — первая фраза):

Маркировка:

## Известные ограничения и решения

- Расчёт по номиналу маркировки; реальные размеры шин разных производителей немного отличаются (это написано под чертежом).
  Ширина диска, вылет, индексы нагрузки и скорости в сравнении не участвуют — только геометрия диаметра, боковины и ширины.
- Спидометр считается относительно текущих шин (сноска об этом есть).
- Нет полудюймовых дисков (R17,5), дюймовых внедорожных обозначений (31×10.5 R15); буква «C» и индексы при вводе текстом игнорируются.
- Safari (WebKit) в этой среде недоступен — проверено в Chromium с профилем iPhone. Используются широко поддерживаемые вещи:
  атрибут `transform` у SVG (твин через rAF, не CSS-анимация SVG), `vector-effect`, container queries (Safari 16+;
  в старых браузерах остаётся одноколоночная раскладка), единицы `cqw` с запасными значениями.
- Сама секция `#shiny` намеренно без класса `.reveal` (он у панели и маркировки внутри): `.reveal` сдвигает элемент на 22 px,
  и ссылка с якорем на такой элемент приземлялась бы под шапкой.
- localStorage (`garage.shiny`, в try/catch) помнит последнюю пару размеров — вернувшийся посетитель видит свои шины.
- **Тизер на главной не добавлял.** Естественное место — строка «Все 28 направлений услуг» внутри секции с интерактивной
  машиной, которую просили не трогать; отдельная полоса между секциями выглядела бы приклеенной. Если нужен — это одна
  ссылка `link-arrow` «Шинный калькулятор →» на `/services/sinomontaz.html#shiny` в `svc-cta`.
- Демо-видео: встроенный рекордер Playwright растягивает время (~×1,14); ролик приведён к реальной скорости через
  ffmpeg `-itsscale 0.88`, курсор (белый кружок) нарисован сценарием записи, на сайте его нет.
