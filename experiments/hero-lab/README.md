# Garage Team: 23 варианта

Изолированная витрина для выбора дизайна: 15 первых экранов и 8 страниц
«первый экран + три блока». Концепции используют подтверждённые факты из сайта, его логотип,
локальные Manrope и JetBrains Mono. Автомобили — концептуальные AI-иллюстрации,
не фотографии клиентов или работ сервиса.

### Сборка для GitHub Pages

В существующей публикации сохраняется основной сайт. Добавляется `docs/hero-lab/`.
Исходные PNG сохраняются в `experiments/hero-lab/assets`; при сборке выдаются
WebP quality 90 (Pillow уже используется проектом). CSS/JS и изображения имеют
версии в URL. Шрифты берутся из существующей сборки основного сайта.

```sh
python3 experiments/hero-lab/build.py --base /garage_team --site-root docs --out docs/hero-lab
python3 experiments/hero-lab/verify_links.py --base /garage_team --site-root docs
```

`--out` задаёт только папку витрины. `--site-root` — папку уже собранного сайта.
Для локального предпросмотра параметры не нужны: используются `dist` и корневые URL.
После полной пересборки основного сайта витрину надо собрать повторно.

## Локальный запуск

Из корня репозитория, если `dist` уже собран:

```sh
python3 experiments/hero-lab/build.py
python3 -m http.server 5183 --bind 127.0.0.1 --directory dist
```

Открыть <http://127.0.0.1:5183/hero-lab/>. Если `dist` отсутствует, сначала
`python3 build.py --reuse-images`. Основная сборка перезаписывает `dist`, поэтому
после неё нужно ещё раз собрать витрину.

Кнопки записи, меню и ссылки на услуги ведут в существующие локальные страницы
основного сайта. Новых форм и подключений к CRM нет. Витрина не добавляется в
основной sitemap, все её страницы имеют `noindex,nofollow`.

## Параллакс

Параллакс работает во всех пятнадцати концепциях:

- №01 — автомобиль и большой GARAGE с разной глубиной.
- №02 — сцена с универсалом за неподвижным текстом.
- №03 — автомобиль, сетка и фоновый B3 с разной глубиной.
- №04 — фотография и крупное garage с разной глубиной.
- №05 — фон, портал, орбита, заголовок, автомобиль и табличка.
- №06–10 — автомобиль или макросцена, в №06–08 также отдельные фоновые слои.
- №11–15 — макросцена и неоновая вывеска с разной глубиной.

Кнопки записи остаются неподвижными. Переключатель №01–04 находится сразу под
первым экраном; у №05 — внутри сцены. У №06–10 переключатель также под экраном.
У №11–15 и переключатель, и навигация по вариантам вынесены за первый экран.
Мышь управляет небольшим смещением; прокрутка добавляет глубину и на телефоне.
Цикл `requestAnimationFrame` затухает при остановке, при скрытой вкладке и вне
экрана. Пользователь может выключить эффект. `prefers-reduced-motion` отключает
параллакс и появление элементов. Скролл страницы остаётся нативным.

## Проверка

Новых зависимостей и браузеров не устанавливает. В этой среде:

```sh
NODE_PATH=/Users/scorpocha/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules \
PLAYWRIGHT_BROWSERS_PATH=/Users/scorpocha/Library/Caches/ms-playwright \
/Users/scorpocha/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node \
experiments/hero-lab/verify.cjs
```

Проверяет 15 вариантов на 7 размерах окна, загрузку визуалов, отсутствие
горизонтального скролла, доступность основной кнопки, мобильное меню, навигацию,
разную глубину слоёв, выключатель параллакса и reduced motion во всех вариантах.
